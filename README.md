# Estavle website

The Estavle home page ("Opción O": the eight-scene illustrated story of a family's first home).
A static site: `index.html` plus `img/`, `vid/` and `brand/`. No build step and no keys.

- Moved here on Nov 23 2026 from the Claude page where it was designed, so the Asset Building team (Max, through the Studio) can work on it.
- Try it locally: open `index.html` in a browser, or run `npx serve .`.
- Nothing here deploys by itself. Going live, and pointing estavle.com at it, is Alvaro's call.
